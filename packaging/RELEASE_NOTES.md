# scrcpy-ez 2.4.0 — scrcpy 5.0.1 与应用投屏体验升级

**本版已升级至 scrcpy 5.0.1**，客户端与 Android 服务端配套协议为 `5.0.1-ez2.4.0`，并更新 FFmpeg 9.0.2 / SDL 3.4.18。默认使用硬件解码，保留图片剪贴板、自适应帧率与码率、通知同步、多设备和应用投屏。

## 推荐主动提高投屏规格

升级后请打开设备卡片的“规格面板”，按手机、电脑和连接条件主动选择更高的长边分辨率、帧率与码率。参数按设备和有线／无线连接分别保存；已有自定义参数会继续保留，需要自行调整。

## 版本特性

- **投屏内核升级**：scrcpy 5.0.1 的硬件解码与新视频缓冲，兼容规格徽标和动态尺寸，保留 ez 图片编解码能力
- **通知点击跳转到投屏**：普通通知可以在应用投屏中打开对应详情；每台设备可在“应用通知 → 通知选项”开关该功能，默认开启，验证码通知仍只复制验证码
- **通知与窗口体验**：改善高清通知图标缩放、通知会话恢复与连续微信消息横幅；默认按设备自然方向创建通知窗口，微信采用原生布局兼容策略
- **应用页面复用与保护**：优先复用兼容的后台应用页面；手机正在使用目标应用或页面布局不兼容时先提示，只有确认“关闭并投屏”才重新打开应用。关闭保留内容的应用窗口时，尽量把任务归还手机后台
- **设置更清晰**：通知跳转与内容选项标明“当前设备”，验证码复制期限标明“所有设备”；自定义参数胶囊及更新下载进度显示更一致
- **无需运行时 PowerShell**：投屏进程信息改为直接调用 Windows COM/WMI，窗口前置校验进程创建时间，处理多设备、应用包名、复杂参数、查询超时和连续点击；关闭投屏继续由原生事件监督器管理所属进程

## 更新、下载与校验

下载 ZIP 与同页的 `SHA256SUMS.txt`，校验后解压并运行 `scrcpy-ez.exe`。推荐使用应用内更新；手动更新前先退出 ez 与投屏并备份原目录，保留自己的 `profiles.json`、`settings.json`、root 偏好及图标缓存。全新安装包只包含空设备档案，不含个人设置、设备记录、通知内容或诊断日志。

GUI、投屏支持脚本、客户端、server 和 DLL 必须整包配套更新。`scrcpy-server-legacy` 仅为历史备份，不能与当前客户端混用；回退请恢复完整旧包。包内 `FILE_SHA256SUMS.txt` 提供逐文件校验。

## 验证与兼容范围

Windows GUI 使用 Windows 子系统构建。完整 Go 回归、并发竞争检测、静态检查，以及 32／64 位原生 WMI 枚举回归通过；C、Android Java 和网页回归及三端 Release 构建通过。内核升级阶段已在 Windows 11、REDMI K80 / Android 16 验证 H.264／H.265、硬件与软件解码、应用虚拟屏和通知链路，后续微信通知方向、窗口关闭后手机状态及应用前台保护有用户实测记录。

不同 APP 的通知详情跳转和后台页面复用仍受 Android／ROM／应用兼容性影响，部分布局需要确认后重新打开应用；不承诺所有通知均可进入精确详情。其他品牌、旧 Android、root、多设备及 USB 插拔未在本次发布新增逐项实机验证；本次原生窗口前置和安全软件提示未新增实机验收。
