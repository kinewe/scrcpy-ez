scrcpy-ez 2.3.0（Windows 64 位）
================================
无需在手机安装 APP，配对后可进行主投屏、应用投屏和通知同步

快速开始
--------
1. 手机开启开发者选项、USB 调试；小米设备控制还需 USB 调试（安全设置）
2. 完整解压后双击 scrcpy-ez.exe，通过 USB 授权或“无线调试”配对手机
3. 在设备卡片启动主投屏；应用窗口可单独投屏一个应用
4. 手机已配对且 ADB 在线即可同步新通知，无需开启投屏
5. 无线投屏需要网络可达，路由器重启或 Wi-Fi 变化会中断连接

2.3.0 新增与改进
----------------
- 手机通知同步至 Windows，支持按设备和应用选择、批量管理、仅验证码、正文预览和复制期限
- 小米系统短信锁屏时若提供独立验证码字段，可显示并复制；号码和正文均隐藏时只显示系统摘要
- 设置“主投屏期间手机不自动休眠”默认开启，所有设备、有线无线主投屏统一适用
- 修改后重新主投屏生效；应用投屏不启用保活，结束主投屏后恢复原有空闲休眠行为
- Ctrl+P 短按手机电源键，可锁屏或唤醒，主投屏及应用投屏窗口均可使用
- 普通与 root 投屏使用同一安装包；已 root 手机可启用上传权限失败后的授权修复
- 已配对设备后台补连、通知断线恢复和电量自动刷新

常用快捷键（投屏窗口有焦点时）
------------------------------
Ctrl+P：手机电源键短按
Ctrl+H：手机物理屏幕黑屏省电／恢复
Ctrl+F：参数控件开关
Ctrl+G：将电脑剪贴板图片保存到手机相册
Ctrl+T：窗口置顶开关
Alt+F：全屏

更新与回退
----------
可通过应用内更新升级；手动更新时先退出 ez 和投屏并备份原目录
已有用户保留 profiles.json、settings.json、root 偏好及图标缓存，不用包内空档案覆盖原档案
GUI、投屏支持.bat、scrcpy 客户端及 server 应整包配套更新
回退时恢复旧程序文件并保留个人配置

兼容与校验
----------
Windows 11、REDMI K80 / Android 16 已实测；其他手机品牌及 root 修复尚未逐一实机验证
通知可读内容由手机系统和来源应用决定；仅验证码模式不会弹出无法识别号码的通知
Release 的 SHA256SUMS.txt 校验 ZIP；包内 FILE_SHA256SUMS.txt 校验其余文件
产品版本 2.3.0；投屏协议保持 4.1-ez2.2.2，详见 RELEASE_NOTES.md
