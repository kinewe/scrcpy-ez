# 任务书：图层名称过滤的泛用性调研

## 背景（一句话）

rc25 原型已验证：用**图层名称过滤**在捕获时排除相机子树，能拿到原生 UI Alpha（企业微信 24.7fps / Steam 31.3fps，2640 帧 CRC 通过，不改 View/背景/Activity）。

## 要回答的问题（开放，方法自选）

1. **这个"图层名称过滤"到底是什么？** Android 原生能力（`SurfaceControl` 隐藏参数 / 私有 flag / `captureLayers` 的扩展）还是**厂商 ROM 扩展**？给出源码或文档依据。
2. **跨设备/跨 ROM**：K80、平板、其他安卓机是否都能用？如果只在某 ROM 可用，**条件是什么**（ROM 版本 / 系统属性 / API 级别）？
3. **TextureView 相机场景**（小红书/支付宝/向日葵）是否适用？**共享纹理/Flutter**（V次元）呢？还是说这条路径只对 SurfaceView 相机有效？
4. **帧率波动**（24.7 → 14.7）的原因？资源泄漏 / 缓存 / 编码器 / 同步等待？
