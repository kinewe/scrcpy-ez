1
开启调试
手机 设置 → 关于手机 → 连点“版本号”7 次打开开发者选项 → 开启 USB 调试（小米还需开启 USB 调试（安全设置））
2
连接投屏
USB 线连接电脑后自动发现设备（约 10 秒），点设备卡“投屏”；无线投屏需与电脑同一网络
3
常用提示
插上 USB 自动切换有线投屏；投屏中点规格胶囊可调参数；停止投屏在设备卡或总览页点击即可
