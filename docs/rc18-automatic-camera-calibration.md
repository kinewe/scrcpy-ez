# RC.18 自动多底色校准

RC.18默认接入新能力，正式启动器与应用投屏入口使用同一实现，不再要求手动加载实验参考图

流程为：创建会话相机 → 几何定位 → 等待真实返回的蓝/黑/白/灰画面 → 各取8个有效样本 → 排除变化明显的像素 → 工作线程求解当前界面参考层 → GPU平滑结合静态参考和实时扫描特效

校准期间沿用已审定的定位环遮罩，局限在相机区域，首个新合成画面就绪后约180ms淡出

- 参考层只在本会话内存中生成，不保存相机采样图，不共用其他应用的参考图片
- 新的相机调用、画面尺寸或色彩元数据变化会重新建立参考
- 采样超时6.5秒，临时工作区限制在4194304像素以内；条件不足时恢复实时透视，避免无限等待
- 初始求解和临时采样内存完成后释放，参考层保留在GPU直到会话结束或重校准
- 动态内容不冻结成静态图；稳定性不足的像素和发生变化的特效由实时路径处理
- 轻微白边、细条带和亮度自适应UI仍可能存在

验证：已知40%黑幕与不透明蓝色控件恢复、移动像素排除、超时/内存边界、GPU界面与扫描覆盖、校准遮罩和淡出、Go应用管理及连接层回归均通过。RC.18正式入口的完整自动流程由用户继续实测；前驱受控原型已获用户确认达到可用程度

保留rc.17-resize8的窗口调整及mDNS优化。相机权限提醒、占用提示、默认开启、重启确认与无边框捕获沿用本次整合修复。活动透视窗口在当前Windows环境中的截图/串流可见性仍有已记录限制
