# scrcpy-ez 2.5.1

**Windows x64 · 基于 scrcpy 5.0.1**

## 更新内容

- **最近打开与手动置顶**　从应用窗口或通知点击打开应用时，立即更新最近记录。手动置顶可以拖动排序，与最近应用共享栏位，默认 4 个，可选 8 个或自行设置。应用列表和消息通知视图共用同一排列，继续支持应用名、包名和中文拼音模糊搜索
- **滚轮兼容模式**　对不响应鼠标滚轮的页面，可在主投屏或应用投屏的设置中开启滚轮转触屏滑动，支持调节滑动幅度和反向。默认关闭，应用投屏按应用保存，有线与无线共用
- **通知跳转与窗口复用**　同一设备上的同一应用已有投屏窗口时，点击通知会复用该窗口并尝试进入对应消息页面。通知入口与普通应用投屏使用相同的防冻结处理
- **应用窗口显示**　默认布局为四行应用及名称留出空间，应用数量显示在底栏。置顶时保留目录原位，便于连续选择和搜索

## 下载与升级

下载 `scrcpy-ez-2.5.1.zip` 和 `SHA256SUMS.txt`，校验并完整解压后运行 `scrcpy-ez.exe`。已有安装可使用应用内更新

常规 ZIP 随附 WebView2 加载器。缺少 WebView2 的电脑可安装 x64 Evergreen Runtime 后重新打开 EZ。[微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/#download)

透视相机依赖手机系统的虚拟相机服务。若手机端服务持续超时，可暂时关闭对应应用的透视相机以继续投屏。完整的运行依赖见[Windows 运行依赖](https://github.com/kinewe/scrcpy-ez/blob/v2.5.1/packaging/WINDOWS-RUNTIME.md)
