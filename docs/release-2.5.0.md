# scrcpy-ez 2.5.0 — 透视相机

**Windows x64 · 基于 scrcpy 5.0.1**

## 更新内容

- **透视相机**：为应用投屏开启透视相机后，应用调用相机时才创建虚拟相机，离开相机界面后释放。支持原生 RGBA 与纯色抠图兼容模式，原生 RGBA 不可用时可自动回退。原生 RGBA 的增量帧支持 Zstd 压缩，减少传输数据量
- **微信扫一扫**：支持的设备卡片可直接打开微信扫一扫投屏。优化扫码页启动、相机准备、校准复用和画面更新，改进关闭窗口时的资源清理
- **投屏与连接**：优化主投屏和应用投屏启动时的设备查询。插线读取到的设备地址可用于尝试无线投屏，连接验证通过后才保存为可用地址。启动和运行中统一检查 ADB 服务能力，发现服务异常时尝试恢复
- **主投屏自动黑屏**：开启后，主投屏画面出现时临时关闭手机屏幕发光。增强对环境光和播放器亮度变化的处理，恢复亮屏或结束投屏时清除临时亮度覆盖。`Ctrl+H` 可手动切换，少数设备在应用调亮度时可能短暂闪亮后恢复黑屏
- **设置和说明**：统一主投屏、应用投屏与全局设置的选项说明，整理设置分类和界面样式，透视相机的强制兼容开关集中在全局设置
- **无线配对优化**：支持通过 5555 端口直连已授权 ADB 调试的设备

## 下载与兼容性

- 下载 `scrcpy-ez-2.5.0.zip`，完整解压后运行 `scrcpy-ez.exe`。已有安装可使用应用内更新
- 如果系统缺少 WebView2，可从 GitHub Release 单独下载微软签名的 `MicrosoftEdgeWebView2RuntimeInstallerX64.exe`，安装后重新打开 EZ。已安装 WebView2 的电脑直接使用常规 ZIP
- 透视相机需要支持虚拟相机的 Android 16 或以上设备，以及支持桌面图形采集和 H.264 编码的 Windows 环境。Windows N 如果缺少 Media Foundation，可安装系统的 Media Feature Pack。详情见[运行依赖](https://github.com/kinewe/scrcpy-ez/blob/v2.5.0/packaging/WINDOWS-RUNTIME.md)
