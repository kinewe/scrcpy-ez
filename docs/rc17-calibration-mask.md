# RC.17 calibration9：扫描区域校准遮罩

基线：`ez-2.4.2-rc.17-resize8`。使用用户确认的五层定位环和粗像素“正在校准”文字，在 Windows 本地绘制独立覆盖层，限定于应用实际显示相机的区域。

## 行为

- 手机仍接收原有校准图和四个定位标记，映射仍由原来的四组颜色计算。
- 首次收到校准帧时，从可见绿底范围确定扫描区域，包括边缘的细小残留。先检测再呈现该帧，不以整页黑底作为未定位时的替代方案。
- **直接用不透明图层盖住这一区域，不抠除定位框，不新增校准颜色抠图着色器。** 区域外的页面正常显示，区域内的悬浮按钮在校准期间会短暂被一起遮住。
- 成功校准后，等待首帧可用的本地透视合成，再用 **180ms** 快速淡出整个覆盖层。不会主动露出仍在传输途中的校准帧。
- 原有透视合成使用检测到的实际可见相机区域作为边界，避免仿射估计误差把顶部几行蓝底留在画面上；微信的绿色扫描动画正常保留。
- 相机关闭或被占用时取消遮罩；失败与等待均有有界回退，不无限遮挡。
- 独立 60Hz 重绘不依赖手机真实桌面送帧档位，淡出结束、窗口最小化或相机关闭后停止动画重绘。不向手机发送动画图片。

## 素材与实现

`assets/calibration` 保存审定抠图、共同中心、五层运动参数和像素字模。`tools/generate_calibration_art.py` 导出原生 PNG 和布局常量，PNG 与审定的源抠图逐像素一致。运行时 `calibration` 目录位于 `scrcpy.exe` 旁，纹理首次使用时载入并复用。

启动器和手机端协议沿用 resize8，保留其 mDNS 和窗口缩放功能。试用包通过 `SOURCE_MANIFEST.json` 标识为 calibration9。

## 验证

`test_calibration_mask.c` 检查首帧门控、180ms 淡出、重入、关闭和超时。原生 SDL 像素校验检查覆盖范围、区域外页面不变和淡出结果。`test_calibration_region.c` 检查顶部不连通细线进入遮罩范围、底部页面排除在外，同时四点映射结果不变。
