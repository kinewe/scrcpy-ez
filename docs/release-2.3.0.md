# scrcpy-ez 2.3.0

本版将手机通知、验证码复制与可选 root 权限修复加入统一运行包，并提供主投屏保活及手机电源键快捷键，无需在手机安装 APP

## 新增与改进

- 手机已配对且 ADB 在线时即可接收新通知，无需开启投屏；支持全局开关、按设备和应用管理、批量修改、仅验证码模式、消息预览及验证码复制期限
- 通知使用来源应用图标，验证码可点击正文或按钮复制；改进 Windows 通知注册、程序迁移、复制动作和断线恢复
- 小米系统短信在锁屏时若仍提供独立验证码字段，ez 可显示并复制号码；若正文和号码均不可读，只显示系统提供的摘要，仅验证码模式会跳过无法识别号码的通知
- 默认开启全局“主投屏期间手机不自动休眠”，统一适用于所有设备的有线、无线主投屏；修改后重新主投屏生效，结束主投屏后恢复空闲休眠，应用投屏不启用保活
- Ctrl+P 短按手机电源键，主投屏和应用投屏窗口均可锁屏或唤醒；保持按键不会触发长按，Ctrl+H 黑屏省电及原有快捷键继续可用
- 普通与 root 设备使用同一安装包；已 root 手机可在规格面板启用“上传权限失败时自动 root 修复”，权限故障后等待 Shell 的 su 授权，针对服务端目录和文件修复，随后仍以普通 Shell 启动服务
- 已入档设备的 mDNS 地址稳定后后台补连，通知监听随真实连接恢复；已连接设备电量自动刷新，通知空白名单可关闭同步，通知设置退出时保存

## 下载与更新

Windows 64 位完整包为 `scrcpy-ez-2.3.0.zip`，完整解压后运行 `scrcpy-ez.exe`，辅助脚本为 `投屏支持.bat`

现有用户可应用内更新；手动更新请先退出并备份，保留原 `profiles.json`、`settings.json`、root 偏好及图标缓存，不用包内空档案覆盖原档案。GUI、客户端、服务端和支持脚本应整包配套更新

[GitHub Release](https://github.com/kinewe/scrcpy-ez/releases/tag/v2.3.0) · [Gitee 发行版](https://gitee.com/kinewe/scrcpy-ez/releases/tag/v2.3.0)

附件含 ZIP 和 `SHA256SUMS.txt`；包内提供逐文件 `FILE_SHA256SUMS.txt` 与 `SOURCE_MANIFEST.json`，不含个人配置、设备记录或调试截图

## 验证范围

Windows GUI、C 客户端与 Android 服务端发布构建通过；Go 的 12 个包、18 份前端测试、真实 C 输入处理器的电源快捷键回归、16 项 Android 通知单元测试及 Windows 原生通知注册、复制、撤回、程序迁移回归通过

发布包校验空设备档案、ZIP CRC 和逐文件哈希；上传后下载两端附件核对 SHA256。GUI 与客户端文件属性统一为 2.3.0，GUI 使用 Windows 子系统且无预发布标记

此前相同功能代码已在 REDMI K80 / Android 16 验证主投屏保活、手动电源休眠、仅剩应用投屏时恢复休眠及锁屏短信验证码。通知可读内容依赖系统与来源应用，其他品牌及 root 手机修复尚未实机验证

Android Release 构建及 lintVitalRelease 通过；完整 lintRelease 尚有通知代码中的 13 项已知错误（API 等级和通知权限检查），本版未将完整 lint 计作通过。投屏线协议保持 `4.1-ez2.2.2`
